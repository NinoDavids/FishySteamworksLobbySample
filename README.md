# 🎮 FishySteamworksLobbySample

A minimal sample project showcasing how to implement multiplayer lobby functionality using **Steamworks**.  
This project is designed as a simple reference for developers who want to understand how lobby systems work without unnecessary complexity.

## 🚀 Features

- Create Steam lobbies
- Join existing lobbies
- Handle lobby member data
- Track player presence
- Basic lobby lifecycle management

## 🧠 Overview

This project demonstrates the core concepts behind Steam lobby systems:

- **Lobby Creation** — initializing a lobby and setting its properties  
- **Lobby Discovery** — finding available lobbies  
- **Lobby Joining** — connecting players into a shared session  
- **Data Synchronization** — storing and retrieving lobby metadata  

It’s intended as a starting point that you can expand into a full multiplayer system.

## ⚙️ Player Management
- Automatic tracking of members  
- Join/leave callbacks  
- Ownership (host) handling

- ## 🧪 Usage

- Create a lobby to host a session  
- Synchronize data between players using lobby metadata

- ## 🔧 Extending This Project

This sample is intentionally simple. You can build on top of it by adding:

- Matchmaking logic  
- In-lobby chat  
- Game state synchronization  
- Dedicated server support  
- UI/UX improvements
